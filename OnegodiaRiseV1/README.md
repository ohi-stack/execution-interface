# OnegodiaRiseV1 Unreal Project Scaffold

This scaffold initializes the Unreal Engine V1 playable prototype layout requested for Task 001.

## Included
- Unreal project root folder: `OnegodiaRiseV1/`
- Content namespace root: `Content/Onegodia/`
- Initial map assets:
  - `Content/Onegodia/Maps/GenesisDistrictOne.umap`
  - `Content/Onegodia/Maps/MainMenu.umap`
- Core content folders for early production organization:
  - `Animations`, `Audio`, `Blueprints`, `Characters`, `Data`, `Maps`, `Materials`, `Meshes`, `Sequences`, `Textures`, `UI`, `VFX`

## Notes
- This change intentionally does **not** add gameplay systems or advanced platform/network/economy systems.
- The `.umap` files are placeholders to reserve required asset names/paths and should be opened/saved in Unreal Editor.
