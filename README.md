# OMOS Node Runtime

Production runtime and documentation platform for **https://omos.onegodian.com**.

## Runtime
- Node >=20
- Express server entrypoint: `server.js`
- Start: `npm start`

## Public Endpoints
- /health
- /api/health
- /manifest
- /api/manifest
- /process (requires `x-omos-key`)
- /dashboard
