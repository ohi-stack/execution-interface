# Shortcodes and generated pages

| Shortcode | Generated page |
|---|---|
| `[algq_trusted_property_contact]` | `/trusted-property-contact/`, `/property-stewardship/` |
| `[algq_stewardship_enrollment]` | `/trusted-property-contact/enroll/` |
| `[algq_stewardship_client_portal]` | `/property-stewardship/portal/` |
| `[algq_property_visit_form]` | Available for restricted staff pages |
| `[algq_stewardship_service_request]` | `/property-stewardship/request-service/` |
| `[algq_stewardship_dashboard]` | `/admin/property-stewardship/` |
| `[algq_stewardship_report]` | `/property-stewardship/documents/` |

Pages are idempotently created during platform activation. The contact page uses the portal's secure-message view.
