Maximum Allowable Offer calculator and underwriting API for Algonquian Real Estate acquisition workflows.

== Description ==

Algonquian MAO Engine provides a WordPress admin calculator, public shortcode calculator, persistence table, and REST endpoints for real-estate acquisition underwriting.

== Shortcodes ==

`[algq_mao_calculator]`

== REST API ==

* `POST /wp-json/algq-mao/v1/calculate`
* `GET /wp-json/algq-mao/v1/calculations`
* `POST /wp-json/algq-mao/v1/calculations`
