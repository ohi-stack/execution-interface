# Admin Guide

Use **Deal Marketplace** in WordPress admin to manage the plugin.

- **Dashboard**: overview and generated page references.
- **Marketplace Deals**: current deal inventory shell and page regeneration bulk action.
- **Buyer Interest**: buyer submissions from the frontend form.
- **NDA Records**: accepted NDA records.
- **Settings**: login/NDA requirements, visibility, support email, and uninstall cleanup controls.
- **Activity Log**: activation, settings, AJAX, NDA, and buyer-interest events.
- **Documentation**: shortcode quick reference.
