# Shortcodes

| Shortcode | Purpose | Access |
| --- | --- | --- |
| `[algq_deal_marketplace]` | Marketplace overview and deal cards | Logged-in users with marketplace view capability |
| `[algq_marketplace_deals]` | Deal list | Verified buyers/managers |
| `[algq_marketplace_deal]` | Individual deal shell | Verified buyers/managers |
| `[algq_marketplace_nda_gate]` | NDA acceptance form | Logged-in users |
| `[algq_buyer_dashboard]` | Buyer workflow status | Verified buyers/managers |
| `[algq_buyer_interest_form]` | Buyer offer/interest form | Buyers with submit capability |

All shortcode attributes are sanitized and rendered output is escaped.
