# Workflow

1. Activate the plugin.
2. Confirm generated pages exist and contain the expected shortcode.
3. Assign `algq_verified_buyer` to approved buyer accounts.
4. Buyer reviews the deal marketplace and buyer deals pages.
5. Buyer accepts the NDA gate for a deal.
6. Buyer submits interest and optional offer details.
7. Marketplace manager reviews Buyer Interest, NDA Records, and Activity Log screens.
