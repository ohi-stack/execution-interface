# Algonquian Tenant Management

Production-oriented WordPress plugin for Algonquian Real Estate, LLC tenant operations.

## Modules

- Tenant CRM
- Lease Management
- Rent Ledger
- Online Payments Integration placeholder
- Maintenance Ticket System
- Notices & Violations
- Document Vault
- Tenant Portal Dashboard
- Move-In / Move-Out Inspections
- Connecticut Compliance Forms

`[algq_tenant_center]`, `[algq_tenant_application]`, `[algq_rent_payment]`, `[algq_maintenance_request]`, `[algq_tenant_forms]`, `[algq_tenant_portal]`, `[algq_tenant_dashboard]`, `[algq_lease_management]`, `[algq_rent_ledger]`, `[algq_maintenance_tickets]`, `[algq_tenant_documents]`, `[algq_move_in_out_inspection]`

`/tenants`, `/tenants/apply`, `/tenants/pay-rent`, `/tenants/maintenance`, `/tenants/forms`, `/tenants/portal`, `/tenants/dashboard`, `/tenants/documents`, `/tenants/lease`, `/tenants/inspection`.

## Security

The plugin uses capability checks, nonces, input sanitization, output escaping, and dedicated database tables. Compliance forms are templates requiring review before use and do not provide legal advice.
