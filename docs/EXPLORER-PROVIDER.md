# Explorer Provider

The server-side `ExplorerProvider` boundary supports network, metadata, transfers, balance, and transaction retrieval. With no configured provider, the UI remains usable while live lookup returns a structured 503. Never expose provider keys to the client.

Canonical production URL: https://odc.onegodian.com. The canonical contract is `0x9eee1e3615efe0374a7588d2760db5ffb2d5ce98` on Ethereum Mainnet (chain ID 1).
