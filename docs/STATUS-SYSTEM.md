# Status System

Allowed states are operational, degraded, partial outage, major outage, maintenance, in development, planned, under review, and discontinued. Overall state uses production-designated services only.

Canonical production URL: https://odc.onegodian.com. The canonical contract is `0x9eee1e3615efe0374a7588d2760db5ffb2d5ce98` on Ethereum Mainnet (chain ID 1).
