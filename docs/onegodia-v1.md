# Onegodia: Rise of the Digital World (V1)

## Prototype Scope
- Third-person exploration/adventure loop in Genesis District One.
- Collect 3 Sovereign Intelligence Fragments.
- Avoid corrupted AI drones with 3 HP health system.
- Activate OHI Core after all fragments are collected.
- Enter unlocked portal to win.

## Controls
- `WASD`: Move
- `Shift`: Run
- `Space`: Jump

## Game States
- Main Menu
- How to Play
- Credits
- Gameplay
- Victory
- Game Over

## Web Build
Runs inside the Next.js app at `/games/onegodia`.
