# INO Platform Plugin

The INO Platform Plugin is the unified digital operating system surface for the Indigenous Nation of Onegodia. It extends the historical OneGodian Members package beyond membership widgets by mapping public website, member dashboard, identity and heritage records, community, programs, volunteers, housing, treasury and grants, learning, events, documents, certificates, communications, media, maps, marketplace, administration, security, integrations, and reporting into one WordPress plugin boundary.

## Production standard

Only features that are fully implemented, documented, tested, permission-controlled, and repeatable should be described to end users as operational. Modules that still require external services or back-office configuration are presented as planning, UI framework, workflow surface, integration boundary, or admin module surfaces until production validation is complete.

## Administrative control panel

The WordPress admin menu is labeled **INO Platform**. It includes the platform module map, WooCommerce product mappings, contributor/creator/affiliate settings, shortcode reference, production checklist, and system status.

## Identity and recognition boundary

Identity declarations distinguish self-declared, family-attested, document-supported, institutionally reviewed, and unverified records. The plugin copy maintains a clear separation between ancestry records, INO membership, and external governmental or tribal recognition.

## Integrations

The plugin is designed to connect through explicit settings and adapters for WordPress, WooCommerce, BuddyPress or BuddyBoss, Google Workspace, Google Maps, email providers, SMS providers, PDF generation, REST APIs, and calendar systems.
