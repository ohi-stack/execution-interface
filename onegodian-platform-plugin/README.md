# OneGodian Platform Plugin moved

The OneGodian Platform Plugin has moved to https://github.com/ohi-stack/onegodian-platform-plugin.

This embedded source directory is deprecated. Use the standalone repository as the canonical source for plugin development, builds, and releases.

No plugin source files should be added back to this directory. Import, package, and release `onegodian-platform-plugin-v1.0.0.zip` from the standalone repository instead.
